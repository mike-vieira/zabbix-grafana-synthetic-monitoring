# Security

Este projeto contém uma versão sanitizada de um template Zabbix destinada à reutilização pública.

Antes de publicar uma nova versão exportada de um ambiente real, revise o diff e não envie:

- credenciais;
- SNMP communities;
- senhas ou tokens;
- nomes de clientes;
- endereçamento de clientes;
- hostnames internos;
- screenshots ou dashboards com dados identificáveis.

A versão pública deve permanecer independente de dados operacionais reais.
